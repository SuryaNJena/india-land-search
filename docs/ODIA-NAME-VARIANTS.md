# Odia search spelling review

## CP1 Explain

English spelling can map to more than one spelling in an Odia record. The bundled list already recognizes both spellings of Jena. The review used to replace one word at a time and did not cover both first letters of Jadumani, so combinations could be missing.

Show all four pairings when a name contains ଜଦୁମଣି or ଯଦୁମଣି and ଜେନା or ଯେନା. Support the equivalent Roman spellings, preserve middle words, and feed the candidates into the existing name-order review. For other Roman names beginning with J or Y, offer the alternate Odia initial when the transliteration produces ଜ or ଯ. Keep aspirated initials intact.

The bundled spelling list is curated. Exact matches in records loaded for the selected state can provide separate evidence. A listed spelling or a record-text match does not confirm land ownership. Checking suggestions remains the user's choice.
