# Plot details, map navigation and land revenue

## CP1 · Explain

Plot Records should make the source text legible, mark the exact parcel on its
sheet, and show the linked Bhulekh holding details when requested. Location
selection should survive an imprecise click. Use the official Odisha e-Pauti
form for land revenue and applicable water tax and its separate receipt page.

## CP2 · Diagram

    Atlas → India → Odisha → district polygon → village boundary
    Plot Info → verify sheet and parcel → shade native geometry
              → confirm khata number → Bhulekh front page
                                       → e-Pauti handoff with visible identifiers

The atlas uses reference boundaries. The official payment form calculates the
current amount and handles the transaction. The application adds no payment
requests or credentials.
