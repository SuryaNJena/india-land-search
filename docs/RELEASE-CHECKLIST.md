# LandReview release checklist

## Challenge release

- [x] Search an Odisha village by English or supported Odia spelling, distinguish same-name villages, and fill verified filters.
- [x] Review local-script and reordered names with Select all and Clear all.
- [x] Run a signed-out fictional name search with no uploads or government portal requests.
- [x] Review colored parcels and download a vector overview filtered to matched sheets.
- [x] Combine both sides of two distinct selected khatas in one PDF. Verify duplicate and missing-side handling.
- [x] Verify browser-local import, workspace checksum, Excel export, and per-plot RoR ZIP.
- [x] Offer direct official routes by map point or known plot ID.
- [x] Document the source history, contributor guide, and reproducible release evidence.
- [ ] Confirm the attendee date and the workshop's exact eight stage labels.

## Live ownership launch

- [ ] Obtain a verified production source with sanctioned statewide name-only access and confirm coverage across all 30 Odisha districts.
- [ ] Verify more Odisha portal village and RI mappings and the plot-to-map identifiers.
- [ ] Confirm reuse, freshness, rate budget, rollback, and realistic load.
- [ ] Verify signed-out production lookup, official live plots and maps, and a complete multi-khata packet against the deployed source.
- [ ] Verify production refresh or source health automation once data access is available.

The challenge demo uses fictional ownership records. See the [data sources](DATA-SOURCES.md) and [verification evidence](CODEX-EVIDENCE.md).
